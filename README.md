# VocabVault

**VocabVault** is a simple and clean vocabulary app built with **Kotlin** that helps you **search for words, understand their meanings, and save them for future reference**.  
Think of it as your personal dictionary + word bank to improve your vocabulary over time ✨

## Features

- Search for English words  
- View word meanings and details  
- Save words to your personal vocabulary vault  
- Delete saved words anytime  
- Clean & minimal UI using **Jetpack Compose**
- Fast and lightweight
